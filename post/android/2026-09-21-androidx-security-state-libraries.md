AndroidX Security State Librariesの安定版が公開  
────────────────────  
AndroidX Security State 1.1.0とSecurity State Provider 1.0.0の安定版が公開されました。アプリ側では、システム・システムモジュール・カーネルのパッチ状態をコンポーネントごとに確認でき、更新クライアントが情報を提供している場合は適用可能な更新も調べられます。  
💬 ── コメント ──  
セキュリティパッチレベルを一つの値だけで判断しているアプリでは、端末の状態をより細かく扱えるか確認するきっかけになりそうです。  

個人的に、直近NFC決済アプリに関わる予定があるので、脆弱性チェックをどのタイミングで落とし込むか押さえておこうと思いました。
